# Flutter workflow standards

Changes to the managed workflow, not the application's release history.
Applications maintain their own root `CHANGELOG.md`.

## Revision 5

- Keep agent guidance focused on setup, implementation, review and verification.
- Discover the workflow from native skill locations in Codex, Claude Code,
  Cursor and Antigravity, including kickoff before app files exist.
- Use the Flutter commit, PR and changelog conventions with the 16 compatible
  universal skills. Scope conflicting universal conventions to other stacks.
- Preserve app decisions and locally edited files during synchronization.
